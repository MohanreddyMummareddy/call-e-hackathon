# CALL-E Hackathon Submission

## Project Overview
Functional software application using CALL-E's API/SDKs for Python/TypeScript or integrating CALL-E Skill/MCP on modern agent environments (Codex, ChatGPT, Claude Code).

## Hackathon Rules Summary
- **Submission Period**: Jul 23, 2026 (9:30pm SGT) – Sep 14, 2026 (11:45am SGT)
- **Feedback Period**: Jul 23, 2026 (9:30pm SGT) – Sep 18 (11:45pm SGT)
- **Judging Period**: Sep 30, 2026 (10:00am SGT) – Oct 13, 2026 (5:00pm SGT)
- **Winners Announced**: ~Oct 19, 2026 (2:00pm SGT)

## Eligibility
- Open to Eligible Individuals (age of majority), Teams, and Organizations
- Excluded: residents of sanctioned countries, promotion entity employees, judges, and conflicts of interest

## Entry Requirements
1. Register on Devpost: [call-e.devpost.com](https://call-e.devpost.com)
2. Obtain CALL-E access (20 free calls new account, or request 200 additional calls)
3. Create a functional Project using CALL-E API/SDKs
4. Submit via Devpost with:
   - Pull request to [CALL-E GitHub repo](https://github.com/CALLE-AI/awesome-phone-call-agents)
   - Demonstration video (<3 min, YouTube/Vimeo)
   - Text description of features/functionality
   - CALL-E account email

## Project Requirements
- Must use CALL-E's API or SDKs (Python/TypeScript)
- Or integrate CALL-E Skill or MCP
- For modern agent environments (Codex, ChatGPT, Claude Code)
- Functional software with real business/project use case

## Judging Criteria (equally weighted)
- **Real World Impact**: Solves actual phone-work problem for real users
- **Quality of the Idea**: Creative, non-obvious use of CALL-E
- **Technical Implementation**: Thorough, skillful use of CALL-E at runtime
- **Product Experience & Demo**: Complete, coherent experience communicated clearly

## Submission Format
- Video: <3 min, YouTube/Vimeo, publicly visible
- Must not include third-party trademarks/copyrighted material without permission
- Provide working project access for testing
- All materials in English or provide translation
